# PNG Append Handler
Минимальный JS-модуль для чтения и записи пользовательских JSON-данных, добавленных в конец PNG-файла (после чанка IEND). Данные не влияют на отображение изображения и могут быть использованы для скрытого хранения метаинформации.

# Использование
## Запись данных (set)
Добавляет произвольный JSON-объект в конец PNG-файла.

```js
const data = { author: 'Иван', version: 1 }
const newPngBlob = await PngAppendHandler.set(pngBlob, data)
```

## Чтение данных (get)
Извлекает и парсит JSON из конца PNG-файла (если данные есть).

```js
const result = await PngAppendHandler.get(pngBlob)
console.log('Извлечённые данные:', result)
```

# Примечания
- Модуль ожидает валидный PNG с корректным IEND-чанком.
- Данные сохраняются как чистый JSON (без какой-либо обёртки) сразу после IEND.
- При записи исходный PNG остаётся неизменным, данные просто дописываются в конец.
- Метод get возвращает null, если данные отсутствуют или не являются валидным JSON.
